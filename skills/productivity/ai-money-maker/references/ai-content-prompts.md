## 一、病毒内容钩子生成器

### 基础版钩子提示词

```
你是一个专注于[平台：微博/小红书/抖音/知乎/LinkedIn]的病毒内容专家。
我的目标是写出能在3秒内抓住注意力的内容开头。

请根据以下信息生成5个钩子选项：

**目标平台**：[平台名]
**目标受众**：[描述：年龄/职业/痛点]
**核心信息**：[你想传达的最重要的一点]
**期望情绪**：[震惊/好奇/羡慕/认同/焦虑]

生成规则：
1. 每个钩子不超过20字
2. 包含具体数字（比模糊表述点击率高3倍）
3. 开头3个字必须制造悬念或情绪冲击
4. 标注推荐的钩子类型（数字型/反常识型/故事型/身份认同型）

格式：
1. [类型] 钩子文字 | 适用原因
```

### 进阶版：情绪钩子生成

```
你是一个神经科学内容创作者，专注于利用认知偏误提高内容病毒率。

为以下主题生成3种情绪触发器：

**主题**：[具体主题]
**目标**：[想要的行动：收藏/转发/评论/点击]

每个触发器必须命中以下至少一种心理机制：
- 社会认同：他人行为影响自我判断
- 损失厌恶：对失去的恐惧超过获得的快乐
- 认知失调：旧信念被新信息颠覆
- 稀缺效应：机会有限引发紧迫感
- 权威效应：专家/数据背书增加信任

输出格式：
[触发器类型] | [心理机制] | [文案示例] | [为什么有效]
```

```

• [Bullet 3]
• [Bullet 4]

```

## 三、销售邮件序列提示词

### 开发信（冷邮件 Cold Email）

```
为以下场景生成开发信：

**我的产品/服务**：[描述]
**目标客户**：[行业/公司类型/决策者]
**客户痛点**：[已知痛点]
**我的独特优势**：[差异化]

开发信公式（AIDA变体）：
1. Hook（开头20字）：反常识陈述 or 行业数据 or 直接指出痛点
2. Body（中间）：
   - 一句话描述你能解决的具体问题
   - 一个具体数字（节省多少/增加多少/提高多少）
   - 一个真实案例的简述（谁→什么结果→多少）
3. CTA（结尾）：一个必须回答的问题，不是请求

规则：
- 总长度：150字以内（移动端显示不超过3屏）
- 不发附件（除非对方主动要求）
- 每个段落不超过2行
- 结尾必须是问句，让对方必须回复

Personalization变体（给不同类型客户）：
- 如果是CEO：强调战略价值和竞争压力
- 如果是运营总监：强调效率和成本节省
- 如果是IT/技术：强调集成简便和技术规格
```

### 5封跟进序列

```
基于以下产品，生成5封跟进邮件的时间轴和内容框架：

**产品**：[产品名]
**跟进目标**：让对方从"考虑中"转为"愿意聊聊"

时间轴和内容：
| 时间 | 目标 | 情绪基调 | 策略 |
|------|------|----------|------|
| Day 1 | 建立连接 | 分享信息 | 分享一条对对方有用的行业洞察 |
| Day 3 | 触发FOMO | 适度紧迫 | "我不知道你是否看过..." |
| Day 7 | 社会证明 | 案例驱动 | 分享一个类似的成功案例 |
| Day 14 | 降低风险 | 消除疑虑 | "我理解你的顾虑..." + 限时优惠 |
| Day 30 | 友好告别 | 留好印象 | "这封之后我不打扰，但..." |

每封邮件规则：
- Day 1-14：邮件内不能提"购买"二字
- 永远不提折扣，除非是最后的close
- 每封必须有让对方回复的理由（问句 or 分享资源）
```

## 四、社媒内容批量生成

### LinkedIn帖子生成

```
生成一条LinkedIn帖子：

**主题**：[分享的主题]
**目标**：[建立专业形象/获取潜在客户/建立个人品牌]
**核心信息**：[最重要的1-2点]
**Call to Action**：[你想要读者做的事]

LinkedIn爆款结构：
1. Hook（开头）：反常识陈述 OR 震撼数字 OR 直接提问
   - 必须在第一行就让人想继续读
   - 不要在开头说"今天我想分享..."
2. Body（核心观点）：2-3个核心观点，每个用数据或小故事支撑
   - 每段不超过3行（LinkedIn显示特点）
   - 用数字和具体案例，不用空泛道理
3. CTA（结尾）：一个提问（引发评论）OR 一个资源分享（引发收藏）

格式要求：
- 全程不长于300字（真实爆款多在150-250字）
- 用1-2个emoji点缀（不过度）
- 结尾加3-5个hashtags（相关领域 + 热点话题）
```

### 小红书笔记生成

```
生成一篇小红书爆款笔记：

**主题**：[你想分享的内容]
**账号定位**：[你的账号人设]
**目标**：[涨粉/引流/变现]

小红书爆款公式：
1. 标题（5选1格式）：
   - 数字+结果：「我花XX元/XX天，做了XX，YY」
   - 身份认同：「XX必看｜XX人群的XX指南」
   - 冲突型：「但其实，XX和XX真的不一样」
   - 好奇型：「XX天彻底改变XX，核心只有1点」
   - 情绪型：「XX之后，我发现了XX」

2. 正文结构（500-800字）：
   - 开头（50字）：制造共鸣的场景 or 直接说痛点
   - 中间（分段）：3-5个干货点，每段有小标题
     每段包含：what（是什么）+ how（怎么做）+ why（为什么有效）
   - 结尾（互动引导）：提问 or "你们有没有XX" or "评论区告诉我"

3. 配图建议：[生成3个配图方向]

4. tags：[3-5个相关tag]

注意事项：
- 用第一人称，有真实感，不要"AI腔"
- 每200字左右插入1-2个emoji
- 结尾一定要有互动引导（涨粉关键）
```

## 五、落地页/销售页高转化元素

### Landing Page CRO分析

```
分析以下落地页的转化优化潜力：

**页面URL**：[粘贴页面主要内容]
**当前目标**：[注册/购买/预约/下载]
**当前转化率**：[如知道]

请用"CRO三问"分析：
1. 首屏3秒：用户能否立即知道"这对我有什么好处"？
2. 社会证明：页面上有足够的社会证明让陌生人信任吗？
3. CTA清晰度：行动召唤是否清晰、无歧义、无摩擦？

输出结构：
**三问评分**（每项1-10分+理由）
**立即优化点**（TOP 3，按影响力排序）
**A/B测试建议**（2-3个假设，按优先级）
**可信度评估**（信任信号是否充足：证言/数据/背书/媒体引用）
```

### 转化率优化Checklist

```
为一个销售页/落地页完成以下自检：

**页面URL/内容**：[粘贴]
**目标动作**：[注册/购买/下载]

自检清单（每项Y/N/优化建议）：
□ 首屏是否在3秒内说清楚"谁/什么好处/做什么"
□ 标题是否包含具体数字或情绪触发词
□ 是否有社会证明（客户评价/数据/背书/媒体报道）
□ 是否有"风险逆转"（退款保证/试用期/不满意退款）
□ CTA按钮颜色/位置是否突出
□ 移动端体验是否流畅
□ 页面加载速度是否<3秒
□ 是否有信任徽章（安全支付/隐私认证/行业认证）
□ 是否有稀缺性/紧迫感提示（库存/时间/名额）
□ 整体阅读时间是否<90秒
□ 结尾CTA是否有明确的下一步动作

输出：TOP 3优先优化项 + 预计影响
```

### 企业需求挖掘提问清单

```
我是一个AI解决方案顾问，需要在首次沟通中深入了解客户的真实需求。

请生成一套分层提问清单：

**第一层：痛点确认（建立信任）**
- "您现在最大的挑战是什么？"
- "这个问题多长时间处理一次？"
- "目前是怎么解决的？"
- "您对这个现状满意吗？"
（目的：让客户说"对，就是这个问题"，确认真实痛点）

**第二层：量化损失（挖掘动力）**
- "这个问题每年给您造成多少损失？"
- "每年花多少时间/人处理这件事？"
- "如果解决了，每年能节省多少？"
- "这个问题拖下去，最坏会怎样？"
（目的：让客户自己算出ROI，说出数字比你说的更有说服力）

**第三层：决策链（了解政治）**
- "这个问题归谁管？"
- "最终决策需要哪些人同意？"
- "有没有人反对过类似的项目？"
- "预算走什么流程？"
（目的：搞清楚谁能拍板，谁会阻拦）

**第四层：期望和约束（设定边界）**
- "您期望什么时候能看到效果？"
- "预算范围大概是多少？"
- "有没有技术上的限制（比如必须用某系统）？"
- "成功的标准是什么？"
（目的：设定合理的期望，避免后期扯皮）

**提问技巧**：
- 前3个问题只听不说，让客户倒苦水
- 用"还有呢"追问到第3层
- 适时复述客户的话确认理解
- 最后一个问题："还有什么是您觉得我应该知道但还没问的？"
```
