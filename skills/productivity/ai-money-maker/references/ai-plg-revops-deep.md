## 一、为什么AI天然适合PLG

AI天然PLG，因为AI生成的东西天然值得分享——图片、代码、文案、报告，都是用户自愿发到社交媒体的「免费营销素材」。

**关键案例：**
- **Cursor**（AI代码编辑器）：0销售团队 → 2024年ARR $40M+，靠Twitter技术社区口碑传播
- **Notion AI**：上线6个月达到$10M ARR，50%新用户来自AI生成内容的二次传播
- **Canva AI**（Magic Write）：嵌入1.2亿月活用户，AI功能付费率22%

| 维度 | 传统SaaS PLG | AI-native PLG |
|------|-------------|---------------|
| 用户获取 | 功能试用（冷） | 产出分享（热） |
| 升级触发 | 功能限制 | 产出限制（用完/慢） |
| 续约率 | 70-80% | 88-95% |
| CAC回收期 | 12-18个月 | 4-8个月 |

## 二、AI PLG的五个核心机制

**机制A：产出即传播（Output-Driven Viral Loop）**
- 用户分享AI生成的图片/代码/报告 → 观看者想「我也要」
- Cursor案例：Twitter上大量「Cursor帮我写了XXX」帖子 → GitHub Stars 0→30,000
- 操作：设计值得截图的AI产出格式（代码高亮/图片对比/报告摘要）

**机制B：使用触发升级（Usage-Triggered Expansion）**
- 当AI使用量达到阈值 → 自动弹出「升级解锁更多」
- 例子：Jasper AI在用户写完第5篇文章后触发升级提示，转化率23%
- 关键：阈值设计要高于免费试用上限，但低于用户「痛点临界点」

**机制C：行为预判流失（Behavioral Churn Prediction）**
- 分析AI使用频率下降模式 → 提前14天预警流失
- Gong AI：记录用户每周对话数下降趋势 → 自动触发挽回邮件
- 结果：挽回率比被动流失后干预高3倍

**机制D：产出嵌入生态（Output Embedding）**
- AI产出直接嵌入用户工作流（Notion/ Slack/ Salesforce）
- Canva AI案例：用户每次用Magic Write生成内容 = 自动推荐设计模板 = 付费转化

**机制E：消费定价PLG（Consumption-Based PLG）**
- 按AI消耗量定价，不是按功能定价
- 用户价值 = (AI节省时间 × 时薪) - 付费金额，值则为正
- 例子：AI代码审查工具 $0.10/行审查，月用量500行 = $50/月 vs 订阅$100/月

## 三、AI客服杠杆：一个人服务1000个客户

**核心逻辑：** AI处理80%标准化问题，人处理20%高价值关系问题。

**AI CS杠杆的四个自动化场景：**
1. **健康评分**：AI分析客户使用行为数据 → 给每个客户打健康分（0-100），CS只处理<60分
2. **流失预警**：使用频率下降超过14天 → AI自动触发挽回序列（3封邮件+1条短信）
3. **知识库自动更新**：产品更新文档自动同步到AI客服知识库，无需人工维护
4. **升级识别**：AI识别高频问题模式 → 自动生成功能需求报告 → 产品团队优先处理

**关键数字：** AI客服处理80%查询，人均管理客户从50→500，CS成本从¥15/人/天降低到¥2/人/天。

## 四、AI RevOps：收入运营的AI自动化

**RevOps核心：** 用AI打通营销、销售、客户成功数据，自动优化收入漏斗。

**AI RevOps工具链：**
- Gong（收入情报）：记录每次销售通话 → AI分析买家痛点/异议 → 培训销售
- Clari（管道预测）：AI预测哪些deal会成交，准确率88%（人类销售预测准确率62%）
- Chorus（对话智能）：AI分析销售对话质量 → 识别最佳实践 → 推广到全团队

**中国案例：** 某AI SaaS公司用钉钉AI + Salesforce插件，实现：
- AI自动录入客户信息（减少销售每天1.5小时录入）
- AI自动分析客户查询内容（判断购买意向）
- 月流水提升¥180,000（AI识别高意向客户 → 销售优先跟进 → 转化率+18%）

## 五、30-60-90天AI PLG启动路线图

**Day 0-30：打基础**
- 分析现有AI产品使用数据（哪个功能用最多/最少）
- 设计第一个「产出值得分享」的AI功能
- 建立使用数据追踪（Mixpanel/Amplitude）

**Day 30-60：跑通PLG环**
- 找10个重度用户测试传播闭环
- 收集第一个100个「AI产出分享」案例
- 优化触发升级时机（用量阈值）

**Day 60-90：规模化**
- 根据使用数据设计定价（消费型 vs 订阅型）
- 建立AI健康评分体系
- 全团队学习AI产出分享数据

## 六、避坑清单

- ❌ 不要在产品不成熟时做PLG——用户第一次体验决定口碑，差评传千里
- ❌ 不要忽视AI产出质量——Low-quality产出 = Low-quality传播
- ❌ 不要只关注用户数——PLG核心是「付费转化率」，不是「注册数」
- ✅ 要设计值得截图的产出格式——Cursor/Github Copilot爆火的关键
- ✅ 要追踪AI使用频率——下降=预警，消失=流失
- ✅ 要让AI产出嵌入用户已有工具——降低切换成本
